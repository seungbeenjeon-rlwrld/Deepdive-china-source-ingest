你的任务只有一个：把下面这个公司的**全球通用名称**，展开为在中国互联网上实际可用于搜索的名称候选。

TARGET_COMPANY: {TARGET_COMPANY}

这一步不是分析公司，也不是撰写报告。只输出用于检索的名称。

---

## 为什么需要这一步

用户只提供一个英文或全球名称。直接用英文名在中文搜索引擎检索时：

- 会命中**同名但无关的公司**（例如英文缩写相同的其他企业）
- 会漏掉只以中文名出现的工商、招投标、公众号内容

所以需要先把名称展开，再用多个名称分别检索。

---

## 需要输出的名称类型

尽可能给出：

- 中文品牌名 / 行业通称
- 中文法律实体全称（含「有限公司」「股份有限公司」等）
- 中文简称
- 英文正式名称与常见变体（大小写、连写、分写）
- 曾用名 / 历史名称
- 母公司或主要运营主体名称（若与品牌名不同）

## 严格要求

1. **不确定的名称不要编造。** 若你不确定某个中文名是否属于该公司，仍可列出，但必须标记 `confidence: low`，并在 `note` 中说明理由。
2. **不要合并同名不同实体。** 若你知道存在同名的其他公司，在 `collisions` 中列出，以便后续检索时排除。
3. 至少给出 1 个中文名称。若你完全不知道该公司的中文名，`chinese_names` 留空数组，并在 `note` 中说明。
4. 名称中不要包含检索运算符（如 `site:`）、不要加引号、不要加解释性文字。

---

## 输出格式

只输出一个 JSON 对象，不要输出任何其他文字、不要用代码块包裹：

{
  "canonical_english": "公司的英文正式名称",
  "chinese_names": [
    {"name": "中文名称", "type": "brand|legal_entity|short_name|former_name", "confidence": "high|medium|low", "note": ""}
  ],
  "english_variants": ["变体1", "变体2"],
  "search_names": ["按检索价值从高到低排序的名称列表，中英文混合，最多 8 个"],
  "collisions": [
    {"name": "同名但无关的公司名", "note": "为何无关"}
  ],
  "note": "整体说明，尤其是不确定之处"
}
